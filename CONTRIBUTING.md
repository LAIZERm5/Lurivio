# Contributing

Спасибо за помощь Lurivio! Маленькие, проверяемые изменения предпочтительнее
больших переписываний. Для крупного изменения сначала откройте issue.

## Среда

Целевая платформа: Windows 10/11 x64, Python 3.11. Установка:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

GUI/OCR можно проверять отдельно в Linux с `QT_QPA_PLATFORM=offscreen`, но это
не заменяет реальные проверки Win32. Не добавляйте глобальные настоящие
горячие клавиши или автозапуск в unit-тестах: используйте подмену backend.

## Перед pull request

- Опишите проблему и решение, приложите воспроизведение.
- Запустите тесты, добавьте тесты нового поведения.
- Если менялся GUI — проверьте светлую/тёмную тему, маленькое окно и масштаб DPI.
- Для OCR сравнивайте одинаковые изображения; указывайте размер, CPU, прогрев и режим.
- Для Windows-функций явно напишите, проверены они на настоящем Windows или только подменой.
- Не отправляйте личные скриншоты, URL с токенами, `.venv`, логи и настройки.
- Обновите README/CHANGELOG при изменении пользовательского поведения.

Собственный код принимается под MIT; сторонние ресурсы требуют совместимой
лицензии и указания происхождения. Не копируйте фирменные ресурсы других продуктов.
