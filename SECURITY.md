# Security

Lurivio — бета-приложение, не инструмент проверки безопасности URL.
Распознанную ссылку нужно проверять перед открытием. Неподписанные бинарники
следует скачивать только из доверенного источника.

## Сообщение об уязвимости

Если владелец репозитория включил **Private vulnerability reporting**, используйте
**Security → Report a vulnerability**. Если функция недоступна, попросите её
включить через issue **без технических деталей эксплуатации**.
Не публикуйте реальные токены, приватные URL или пользовательские скриншоты.

## Границы

- Программа копирует текст, но не открывает ссылку и не отправляет запрос.
- Скриншоты обрабатываются в памяти. После установки OCR не использует сервер.
- История/облачная синхронизация буфера находятся вне контроля Lurivio.
- Автозапуск включается только пользователем в его HKCU Run.
- Библиотеки и OCR-модели требуют регулярной проверки обновлений и лицензий.

Проект не предоставляет SLA или обещания срока исправления. Рекомендуется
использовать последний проверенный релиз и поддерживаемую ОС.
