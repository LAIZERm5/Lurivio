- [ ] Проверены права на название для предполагаемых стран распространения.

- [ ] QR с текстом/опасной схемой не копируется автоматически и не запускается.
- [ ] Режимы авто/OCR/QR работают, сохраняются, не смешивают кэш.

- [ ] Один ЛКМ по трею — выделение, ПКМ — меню, открыть окно через меню, нет двойного захвата.
- [ ] Изменение горячих клавиш, занятое сочетание, сброс и Ctrl+V проверены.
- [ ] Кнопки окна справа: свернуть/развернуть/закрыть; закрытие в трей по настройке.
- [ ] Трей, уведомления и полный выход не оставляют лишнего процесса.
- [ ] RU/EN, все темы и маленькое окно без наложений.
- [ ] Автозапуск проверен реальным выходом/входом в Windows.
- [ ] Обновление со ScreenLink не оставило две записи автозапуска.

## Публикация

Тег v0.6.1 создаёт draft prerelease. Проверьте вложенные ZIP и SHA256SUMS,
затем вручную нажмите Publish release. Не объявляйте стабильную поддержку Windows
до реальной проверки. SHA-256 проверяет целостность, но не заменяет цифровую подпись.
