# Быстрая работа Lurivio

## Для текстовых ссылок

- Выберите «Только ссылки (OCR)», если QR не нужен: проверка QR будет пропущена.
- Включите быстрый режим строки и дождитесь готовности OCR после запуска.
- Выделяйте одну горизонтальную строку с небольшими полями.
- Поставьте видео на паузу; увеличьте слишком мелкий адрес.
- Режим «строка» пропускает детектор при уверенном результате; «область» — запасной путь.

Не снижайте порог уверенности только ради скорости: это повышает риск ошибок.

## Для QR

- Выберите «Только QR-коды»: OCR для выделения не вызывается.
- Выделяйте целиком код и светлую рамку, без лишнего фона.
- Маленький, обрезанный или смазанный код может потребовать увеличение изображения.
- В «Авто» найденный QR имеет приоритет; соседний текст не распознаётся одновременно.
- В очень узкой области строки «Авто» пропускает QR-проверку.

## Что оптимизировано

Модель OCR постоянная и прогретая, QR-детектор повторно используется в том же рабочем потоке.
Обработка не блокирует интерфейс. Нет сохранения PNG для распознавания; подготовка в памяти.
Кэш использует точное совпадение пикселей, размеров, быстрого режима и режима OCR/QR/Авто.
Смена режима не возвращает чужой кэш. «Очистить» очищает текущий результат и кэш.

Время внизу окна показывает обработку задания: не выбор мышью, очередь, загрузку
модели и показ уведомления. Повтор из кэша — пропуск распознавания, не ускорение модели.
Скорость зависит от CPU, нагрузки, размера области, шрифта и качества изображения.
Не рассматривайте время одного тестового скриншота как гарантию для Windows.

## Если медленно

В issue укажите CPU, RAM, масштаб Windows, размер области, режим, время и первый
ли это запуск. Прикладывайте только безопасные тестовые примеры без личных данных.
