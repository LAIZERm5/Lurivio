# Lurivio 0.6.1 — проверки

## Выполнено локально

Среда: Linux, Python 3.9, Qt offscreen, PySide6 6.8.3, OpenCV 4.x, ZXing-C++ 2.3.0.
Целевая среда: Windows 10/11 x64, Python 3.11. Это разные среды.

- **74 теста**, включая настоящий OCR на светлом/тёмном фоне; без пропусков.
- QR-декодирование реальных сгенерированных кодов: HTTP/HTTPS, Unicode, многострочный текст, Wi-Fi.
- Поворот, инвертированный QR, несколько кодов, пустое изображение, дедупликация и ограничения данных.
- При найденном QR не вызывается OCR; QR-only без OCR-фолбэка; OCR-only без QR-проверки.
- GUI: QR URL автокопируется, текст/Wi-Fi/не-web-схемы не копируются автоматически.
- Выбор второго результата, ручное копирование, очистка QR-состояния при возврате к OCR.
- RU/EN не меняет исходные QR-данные; режим сохраняется в настройках.
- Миграция настроек предыдущих версий без изменения старого файла.
- Реальный рабочий поток: QR → буфер, точный повтор → QR-кэш, Wi-Fi → ручное копирование, OCR-only → буфер.
- Визуальная проверка пяти тем, RU/EN, галереи, QR-результата и небольшого окна.
- Флаги нативной панели Windows сохранены; нет Frameless у основного окна.

Команда:

```powershell
$env:LURIVIO_HOME = "$env:TEMP\lurivio-tests"
$env:LURIVIO_TEST_OCR = "1"
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

- Запись реальными Qt-событиями клавиш, колёсика и боковой кнопки; Esc, отмена, запрет мыши без модификатора.
- Поле read-only открывает окно записи по ЛКМ и получает сочетание без печати текста.
- Переключение keyboard → mouse → keyboard, сохранение прежнего сочетания при ошибке установки.
- Приостановка/восстановление сочетания и обработка конфликта при восстановлении.
- Tray Trigger запускает захват ровно один раз; Context не запускает; двойные события объединяются; busy/recording блокируют захват.

- Версия интерфейса, перевода и Windows-ресурсов сверяется с VERSION. Проверен draft-only workflow с запретом перезаписи опубликованного релиза.

- Дополнительные синтетические QR: округлённые модули (прямой/инвертированный), логотип в центре, JPEG-сжатие, цветной низкоконтрастный код, тесная обрезка и плотный код внутри 4K-кадра.
- Частично стёртый нечитаемый код не возвращает выдуманный результат.

- Реальный рабочий поток с новым движком: округлённый QR → фоновые попытки декодирования → точная ссылка в буфере обмена.

## Не проверено здесь

Настоящий Windows-захват, RegisterHotKey, WH_MOUSE_LL, физические боковые кнопки/драйверы мыши, системный трей/уведомления, возврат фокуса,
HKCU Run и вход в Windows, разные DPI/мониторы, native caption/Snap, запуск
PyInstaller EXE на чистом Windows без Python. Все пункты — в RELEASE_CHECKLIST_RU.md.
Системная панель Windows рисуется вне клиентской области и на локальных снимках отсутствует.

GitHub Actions в этой сессии не запускался. Репозиторий и релиз не опубликованы.
Готового EXE в исходном ZIP нет. Workflow готовит черновик prerelease после успешной сборки,
но не заменяет ручную проверку на Windows. Время обработки на скриншоте — один тестовый
пример, не гарантированная производительность.

Конкретный проблемный QR из видео пользователя не предоставлен и не проверен. Нельзя гарантировать чтение любого стилизованного Telegram QR.
