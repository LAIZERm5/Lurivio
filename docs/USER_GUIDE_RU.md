# Lurivio — руководство

## Захват

1. Откройте изображение или поставьте видео на паузу.
2. Нажмите Ctrl+Shift+L (или свою комбинацию).
3. Обведите строку адреса либо QR целиком со светлым полем вокруг.
4. Отпустите мышь и дождитесь уведомления.
5. Вставьте через Ctrl+V / «Вставить».

Esc и правая кнопка отменяют выделение. Выделение работает на мониторе под курсором.
Если код/ссылка не найдены, увеличьте изображение и повторите.

## QR-коды

В настройках: авто / только ссылки (OCR) / только QR.
Авто сначала проверяет QR; при найденном коде OCR не выполняется. Иначе используется OCR.
Очень узкая область пропускает QR-проверку в авто. QR-only не распознаёт текст рядом с кодом.
Несколько найденных кодов показываются в списке; не все повреждённые коды могут прочитаться.

Одиночная корректная HTTP/HTTPS-ссылка может копироваться автоматически.
Для обычного текста, Wi-Fi, контакта или другого содержимого нажмите «Копировать» вручную.
Можно отредактировать QR-текст, включая несколько строк. Смена языка не переводит данные.
Программа ничего не открывает, не исполняет и не подключает Wi-Fi.
Вставлять непроверенный QR-текст в терминал опасно — сначала просмотрите содержимое.

## Язык, клавиши и темы

Настройки → Язык интерфейса → English / Русский. Изменение сразу и сохраняется.
Настройки → Горячая клавиша → нажмите поле → НАЖМИТЕ сочетание → Применить.
Откроется окно записи: текст не нужно вводить. Клавиатура: например Ctrl+Alt+K.
Мышь: держите модификатор и нажмите колёсико или боковую кнопку внутри окна записи.
MouseMiddle — колёсико, MouseX1/MouseX2 — боковые кнопки. Без модификатора, ЛКМ/ПКМ
и прокрутка не назначаются. Esc / «Отмена» оставляет прежнее сочетание.
Старый захват приостановлен на время записи. Изменение включается кнопкой «Применить».
При занятой новой комбинации остаётся старая. Ctrl+C/X/V и F12 запрещены для захвата.
«Сбросить» — Ctrl+Shift+L, если свободна. Оформление переключается в разделе тем.

## Окно и трей

Windows-кнопки справа сверху: свернуть в панель задач, развернуть, закрыть.
По умолчанию закрытие скрывает приложение в трей; это можно выключить в настройках.
Один ЛКМ по значку трея сразу начинает выделение. ПКМ → «Открыть Lurivio» — окно.
Нажатие уведомления открывает результат. Полный выход: значок Lurivio → «Завершить». Автозапуск при входе Windows включается отдельно,
стартует скрыто. Переместили папку? Выключите и включите автозапуск из новой копии.

## Приватность и обновление

Настройки: %LOCALAPPDATA%\Lurivio. Снимки/история не сохраняются и не загружаются.
«Очистить» удаляет текущий результат и кэш, но не буфер Windows. Его история/синхронизация
подчиняется Windows. Ошибки запуска: Diagnose.bat; технический журнал — errors.log.

При обновлении Lurivio выключите старый автозапуск и полностью завершите старую
программу. На первом запуске без новых настроек читаются только прежние настройки;
старые файлы и автозапуск не удаляются. Включите автозапуск заново в Lurivio.

Приложение в бета-статусе. Проверьте домен и OCR-символы перед открытием ссылки.
